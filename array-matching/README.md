# Assignment 3 — Array Matching

Reads two integer arrays from a file and solves a matching problem between
them. Two independent solution attempts are kept side by side:
`ArrayMatch.java` and `ArrayMatch2.java`. Both are verified against the
same 6 input fixtures (`input00.txt`–`input05.txt`). `assignment3-writeup.pdf`
is the accompanying written report.

## Running

```bash
javac ArrayMatch.java
java ArrayMatch input00.txt
```
